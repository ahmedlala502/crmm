# Pipedrive-Class CRM Build Kit

Generated from a functional inspection of Pipedrive's current product model as of 2026-09-03.

Files:
- `MASTER_BUILD_PROMPT.md` — paste into Claude Code, Codex, Gemini CLI, Qwen, GLM, OpenCode, Cursor, Lovable, Replit, Base44, etc.
- `SKILL.md` — reusable skill/instruction file for an agent system.
- `FEATURE_INVENTORY.md` — functional reference / acceptance checklist.
- `config_blueprint.json` — machine-readable module/config blueprint.

Excluded by design:
- onboarding tours
- Academy/training content
- tutorial/demo videos
